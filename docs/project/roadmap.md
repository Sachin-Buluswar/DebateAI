# UI/UX Improvements Roadmap

## Status

Mobile responsiveness is functional across all core pages (375px, 768px, 1920px). The items below are **enhancements**, not critical fixes.

---

## Priority 1: Mobile Polish

### Debate Page
- [ ] Stack panels vertically on small screens
- [ ] Swipeable tabs for participant/wiki panels
- [ ] Floating action button for primary actions

### Speech Feedback
- [ ] Full-screen recording mode on mobile
- [ ] Large touch targets (min 48px)
- [ ] Gesture-based controls

### Dashboard
- [ ] Mobile-friendly chart alternatives for Recharts
- [ ] Horizontal scrolling for data tables
- [ ] Card-based metrics that stack vertically

---

## Priority 2: Loading & Empty States

### Skeleton Screens
- [ ] Dashboard data loading
